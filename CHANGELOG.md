## [0.1.0] - 2023-05-30

### Added
- Initial release of IronLionUUID
- Core UUID functionality with bit-level configuration
- Support for parameter, environment variable, timestamp, sequence, and random attributes
- Rails integration with ActiveRecord type casting
- SQL function generation for PostgreSQL, MySQL, and SQLite
- Rails generators for installing database functions
- Basic documentation and examples
